# 💻 Meu Portfólio Pessoal

**Aluno:** Matheus Rodrigues

## Sobre o projeto

Este projeto é meu portfólio pessoal, criado para apresentar um pouco sobre mim, meus estudos e os projetos que desenvolvi durante o curso de Desenvolvimento de Sistemas.

A ideia é mostrar minha evolução na área de tecnologia e compartilhar meus conhecimentos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- GitHub Pages

## O que o site apresenta?

O portfólio possui quatro seções principais:

- **Perfil:** apresentação pessoal.
- **Projetos:** alguns trabalhos que desenvolvi durante os estudos.
- **Habilidades:** tecnologias e assuntos que estou aprendendo.
- **Contato:** espaço para informações de contato.

Também possui um menu para facilitar a navegação entre as seções.

## Recurso novo adicionado

O recurso novo que escolhi foi a inclusão de uma seção de habilidades e animações nos elementos do site.

As animações fazem os cartões e textos aparecerem suavemente quando a pessoa navega pela página.

Também coloquei efeitos nos cartões quando o visitante passa por eles.

## Como esse recurso foi feito?

Utilizei CSS para criar os efeitos de movimento e mudança de aparência.

Também utilizei JavaScript com IntersectionObserver para identificar quando os elementos aparecem na tela e iniciar as animações.

A seção de habilidades foi organizada utilizando HTML, CSS e Bootstrap.
